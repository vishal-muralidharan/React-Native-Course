# React Native Projects

## Description
A comprehensive repository of React Native projects exploring core concepts like navigation, API routing, UI styling, and networking. These sample apps demonstrate foundational and advanced techniques, including drawer, stack, and tab navigation, alongside cross-platform compatibility, layout structures, and form handling.

## Projects Included

* APIRoutesApp - API routing implementation
* CoreComponents - Standard React Native components
* DrawerNavigationApp - Drawer navigation setup
* DynamicUI - Responsive and dynamic user interfaces
* FundamentalsApp - Basic React Native fundamentals
* HelloWorld - Introductory starter app
* ModalApp - Modal and transparent screen examples
* PlatformApp - Platform-specific code implementation
* Pokemon - API data fetching and display
* RNForm - Form handling and validation
* RNLayout - Flexbox and layout structures
* RNList - FlatList and SectionList implementations
* RNNavigation - React Navigation basics
* RNNavigation2 - Advanced navigation concepts
* RNNavigationOld - Legacy navigation implementation
* RNNetworking - HTTP requests and networking
* StackNavigationApp - Stack navigation examples
* StylingRN - StyleSheet and UI styling techniques
* TabNavigationApp - Bottom tab navigation setup

## How to Run

1. Navigate to the specific project folder you want to run:
   cd <ProjectFolderName>

2. Install the required dependencies:
   npm install

3. Start the development server:
   npx expo start
